# Deep Learning - Bài tập môn học

Repository này dùng để tổng hợp và lưu trữ các bài tập trong quá trình học môn **Deep Learning**. Các bài tập được tổ chức dưới dạng tài liệu Word, phục vụ việc học tập, thực hành và ôn tập các kiến thức đã học.

## Danh sách bài tập

| Bài tập | Chủ đề |
|---|---|
| BT02 | Logistic Regression và Computation Graph |
| BT03 | Perceptron |
| BT04 | Multi-Layer Perceptron (MLP) |

## Cấu trúc repository

```text
Deep_Learning_02/
├── BT02_ComputationGraph.docx

```

## Mục đích

- Tổng hợp các bài tập của môn Deep Learning tại một nơi.
- Lưu trữ tài liệu để thuận tiện tra cứu và ôn tập.
- Theo dõi quá trình học tập và thực hành các kiến thức về Deep Learning.

## Ghi chú

Repository phục vụ mục đích học tập cá nhân. Nội dung bài tập được lưu trong các file Word tương ứng.
